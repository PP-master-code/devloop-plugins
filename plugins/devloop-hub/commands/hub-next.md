Use the dev_loop hub's MCP tools (server `devloop`; if you have the hub connected under another name, use that).

1. Call the hub tool `next` (with `project` = "$ARGUMENTS" if given, else without). If it carries open notes or
   says the recommendations changed, show them to me first.
2. List what it offers: project, id, title, `size`, recommended `model`, dependencies. Say which one you would pick
   and why (size fits the session, the model I am running matches the recommendation).
3. Ask whether I want to start it. On yes, continue as `/hub-start <project> <id>` does. Do not claim anything
   before I say yes.

New to the hub? Call the hub tool `guide` first; it is the reference for the whole flow.
